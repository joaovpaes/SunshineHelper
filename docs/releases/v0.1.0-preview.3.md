## English

**Summary:** the third test version. The **Devices screen** now works: it lists every device that has connected, by the name Moonlight reports, so you no longer have to guess or type that name by hand when you set up a profile. It still has no installer and no code signing (SmartScreen warning).

### What changed
- **New, Devices screen:** the **Devices** entry in the side menu used to say "coming in a later PR". It now lists the devices that have connected, and for each one shows the name (as Moonlight reports it), how many times it connected, when it last connected and which profile was used. If no profile matched the device, the line says "none matched" — that is the case where you probably want to create a profile for it. The list updates by itself if a device connects while the screen is open.
- **New, Forget device:** select a device and click **Forget device** to remove it from the list. This only deletes the record; your profiles are not touched, and the device shows up again on its next connection.
- **New, a small file on your PC:** the list is kept in `devices.json`, next to `settings.json` (in `%LOCALAPPDATA%\SunshineHelper`). It keeps only the device name, the first and last connection, the number of connections and the last profile used. It never stores IP addresses, MAC addresses or Sunshine keys, and keeps at most 100 devices. Nothing is sent over the internet.
- **Safe by design:** noting a device can never stop or slow down a stream. If the file cannot be read or written, the app writes a line to `app.log` and the stream goes on as usual.

### How to update
1. Quit the app: right-click the tray icon and choose **Exit** (**Sair** in the Portuguese interface).
2. Unzip the new zip and **replace** `SunshineHelper.exe` and `SunshineHelper.Trigger.exe` in your folder with the new ones.
3. Open `SunshineHelper.exe`. Your settings and profiles are kept, and so is the "Start with Windows" option. Nothing changes in Sunshine.
4. The Devices list **starts empty**: it fills up from the next streams (the app cannot know about past connections).

### What does not work yet or needs care
- **No installer and no code signing** (hence the SmartScreen warning).
- The Devices screen was covered by automated tests, but this is the first package with it: if something looks wrong, please say so (the diagnostic report on the General screen helps).
- A session resumed after a disconnect (seen only through the Sunshine log) does not count as a new connection.
- There is no "Create profile for this device" button yet: for now, copy the name from the list into the **Profiles** screen. The button is the next step.
- The **Log** screen and the gamepad overlay do not exist yet.
- If you open a second copy of the app, it closes silently (only one copy can be open): use the tray icon to bring the window up.
- Tested so far only on Windows 11, with Sunshine for Windows, RTSS 7.3.x and Playnite.

### How to check the file
Compare the zip's SHA256 with the `SHA256SUMS.txt` on this page (in PowerShell: `Get-FileHash .\file.zip`).

## Português

**Resumo:** terceira versão de testes. A **tela Dispositivos** agora funciona: ela lista todos os aparelhos que já conectaram, pelo nome que o Moonlight informa, então você não precisa mais adivinhar nem digitar esse nome à mão ao montar um perfil. Continua sem instalador e sem assinatura de código (aviso do SmartScreen).

### O que mudou
- **Novo, tela Dispositivos:** a entrada **Dispositivos** do menu lateral dizia "chega em um próximo PR". Agora ela lista os aparelhos que já conectaram e mostra, para cada um, o nome (como o Moonlight informa), quantas vezes conectou, quando foi a última conexão e qual perfil foi usado. Se nenhum perfil correspondeu ao aparelho, a linha diz "nenhum correspondeu", que é justamente o caso em que você provavelmente quer criar um perfil para ele. A lista atualiza sozinha se um aparelho conectar com a tela aberta.
- **Novo, Esquecer aparelho:** selecione um aparelho e clique em **Esquecer aparelho** para tirá-lo da lista. Isso só apaga o registro; os seus perfis não são mexidos, e o aparelho aparece de novo na próxima conexão.
- **Novo, um arquivo pequeno no seu PC:** a lista fica em `devices.json`, junto do `settings.json` (em `%LOCALAPPDATA%\SunshineHelper`). Guarda só o nome do aparelho, a primeira e a última conexão, o número de conexões e o último perfil usado. Nunca guarda endereço IP, MAC nem chaves do Sunshine, e mantém no máximo 100 aparelhos. Nada é enviado pela internet.
- **Seguro por projeto:** anotar um aparelho nunca pode impedir nem atrasar uma transmissão. Se o arquivo não puder ser lido ou gravado, o app escreve uma linha no `app.log` e a transmissão segue normalmente.

### Como atualizar
1. Saia do app: clique com o botão direito no ícone da bandeja e escolha **Sair**.
2. Descompacte o zip novo e **substitua** `SunshineHelper.exe` e `SunshineHelper.Trigger.exe` na sua pasta pelos novos.
3. Abra o `SunshineHelper.exe`. Suas configurações e perfis são mantidos, e a opção "Iniciar com o Windows" também. Nada muda no Sunshine.
4. A lista de Dispositivos **começa vazia**: ela vai enchendo a partir das próximas transmissões (o app não tem como saber das conexões passadas).

### O que ainda não funciona ou exige cuidado
- **Sem instalador e sem assinatura de código** (por isso o aviso do SmartScreen).
- A tela Dispositivos tem testes automáticos, mas este é o primeiro pacote com ela: se algo parecer errado, avise (o relatório de diagnóstico da tela Geral ajuda).
- Uma sessão retomada depois de uma desconexão (vista só pelo log do Sunshine) não conta como nova conexão.
- Ainda não há o botão "Criar perfil para este aparelho": por enquanto, copie o nome da lista para a tela **Perfis**. O botão é o próximo passo.
- A tela **Log** e o overlay pelo controle ainda não existem.
- Se você abrir uma segunda cópia do app, ela fecha em silêncio (só pode haver uma cópia aberta): use o ícone da bandeja para trazer a janela.
- Testado até agora só em Windows 11, com o Sunshine para Windows, RTSS 7.3.x e Playnite.

### Como conferir o arquivo
Compare o SHA256 do zip com o `SHA256SUMS.txt` desta página (no PowerShell: `Get-FileHash .\arquivo.zip`).
