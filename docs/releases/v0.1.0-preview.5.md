## English

**Summary:** the fifth test version. It adds the **Log screen**, so you can read what the app did without opening `app.log` by hand, and the guide inside the zip now explains the setup you have to do (including **Super Resolution** for resolutions above your monitor's) and what the app does not cover. It still has no installer and no code signing (SmartScreen warning).

### What changed
- **New, Log screen:** the **Log** entry in the side menu used to say "coming in a later PR". It now shows the end of the app's own log (`app.log`, the last 500 lines), in a fixed-width font, scrolled to the latest line. It updates by itself while the screen is open, so lines from a stream that is running show up without clicking anything.
- **New, only warnings and errors:** tick **Show only warnings and errors** to see just the `[WARNING]` and `[ERROR]` lines. Untick it to see everything again.
- **New, Copy and Open log folder:** **Copy** puts the text on the screen on the clipboard (read it before sharing it: it is meant to be redacted, but you should check). **Open log folder** opens the folder where `app.log` lives in Windows Explorer.
- **Only reads the file:** the screen never changes the log or sends it anywhere. If the file does not exist yet, it says so.
- **Better guide (`LEIA-ME.md` in the zip) and README:** new sections explain the setup you have to do (Sunshine log level, log path, Prep Commands, app open before the stream, RTSS, and **Super Resolution**: turn on VSR on AMD or DSR on NVIDIA so Windows offers resolutions above the monitor's) and the **known limits** (Sunshine's own monitor problems are not covered, a monitor without HDR cannot use the HDR option, refresh rate is never changed, only the primary monitor is handled).
- **Already tested before this version:** the **Create profile for this device** button from preview.4 was checked on a real PC (name filled in, profile saved, next stream used it).

### How to update
1. Quit the app: right-click the tray icon and choose **Exit** (**Sair** in the Portuguese interface).
2. Unzip the new zip and **replace** `SunshineHelper.exe` and `SunshineHelper.Trigger.exe` in your folder with the new ones.
3. Open `SunshineHelper.exe`. Your settings, profiles, device list and the "Start with Windows" option are kept. Nothing changes in Sunshine.

### What does not work yet or needs care
- **No installer and no code signing** (hence the SmartScreen warning).
- The Log screen has automated tests for its filter, but this is the first package with the screen itself: if something looks wrong, please say so (the diagnostic report on the General screen helps).
- The Log screen shows only the app's own log, not the Sunshine log.
- If the GPU driver does not offer the resolution of a profile, the app logs "resolution change refused by the video driver" and the stream goes on without it: see the Super Resolution section of the guide.
- The gamepad overlay does not exist yet.
- If you open a second copy of the app, it closes silently (only one copy can be open): use the tray icon to bring the window up.
- Tested so far only on Windows 11, with Sunshine for Windows, RTSS 7.3.x and Playnite.

### How to check the file
Compare the zip's SHA256 with the `SHA256SUMS.txt` on this page (in PowerShell: `Get-FileHash .\file.zip`).

## Português

**Resumo:** quinta versão de testes. Ela traz a **tela Log**, para você ler o que o app fez sem abrir o `app.log` à mão, e o guia que vai dentro do zip agora explica as configurações que você precisa fazer (inclusive a **Super Resolução**, para resoluções maiores que a do monitor) e o que o app não cobre. Continua sem instalador e sem assinatura de código (aviso do SmartScreen).

### O que mudou
- **Novo, tela Log:** a entrada **Log** do menu lateral dizia "chega em um próximo PR". Agora ela mostra o fim do log do próprio app (`app.log`, as últimas 500 linhas), em letra de largura fixa, já rolado até a última linha. Ela atualiza sozinha com a tela aberta, então as linhas de uma transmissão em andamento aparecem sem você clicar em nada.
- **Novo, só avisos e erros:** marque **Mostrar só avisos e erros** para ver apenas as linhas `[WARNING]` e `[ERROR]`. Desmarque para ver tudo de novo.
- **Novo, Copiar e Abrir a pasta do log:** **Copiar** coloca o texto da tela na área de transferência (leia antes de compartilhar: ele deve sair com dados sensíveis ocultados, mas confira). **Abrir a pasta do log** abre, no Explorador do Windows, a pasta onde fica o `app.log`.
- **Só lê o arquivo:** a tela nunca altera o log nem o envia para lugar nenhum. Se o arquivo ainda não existir, ela avisa.
- **Guia melhor (`LEIA-ME.md` do zip) e README:** seções novas explicam as configurações que você precisa fazer (nível de log do Sunshine, caminho do log, Prep Commands, app aberto antes da transmissão, RTSS e **Super Resolução**: ligue o VSR na AMD ou o DSR na NVIDIA para o Windows oferecer resoluções acima da do monitor) e os **limites conhecidos** (problemas do próprio Sunshine com o monitor não são cobertos, monitor sem HDR não usa a opção de HDR, a taxa de atualização nunca muda e só o monitor principal é tratado).
- **Já testado antes desta versão:** o botão **Criar perfil para este aparelho** da preview.4 foi conferido num PC de verdade (nome preenchido, perfil salvo, transmissão seguinte usou o perfil).

### Como atualizar
1. Saia do app: clique com o botão direito no ícone da bandeja e escolha **Sair**.
2. Descompacte o zip novo e **substitua** `SunshineHelper.exe` e `SunshineHelper.Trigger.exe` na sua pasta pelos novos.
3. Abra o `SunshineHelper.exe`. Suas configurações, perfis, lista de aparelhos e a opção "Iniciar com o Windows" são mantidos. Nada muda no Sunshine.

### O que ainda não funciona ou exige cuidado
- **Sem instalador e sem assinatura de código** (por isso o aviso do SmartScreen).
- A tela Log tem testes automáticos para o filtro, mas este é o primeiro pacote com a tela em si: se algo parecer errado, avise (o relatório de diagnóstico da tela Geral ajuda).
- A tela Log mostra só o log do próprio app, não o log do Sunshine.
- Se o driver da placa não oferecer a resolução de um perfil, o app registra "Troca de resolução recusada pelo driver de vídeo" e a transmissão segue sem ela: veja a seção de Super Resolução do guia.
- O overlay pelo controle ainda não existe.
- Se você abrir uma segunda cópia do app, ela fecha em silêncio (só pode haver uma cópia aberta): use o ícone da bandeja para trazer a janela.
- Testado até agora só em Windows 11, com o Sunshine para Windows, RTSS 7.3.x e Playnite.

### Como conferir o arquivo
Compare o SHA256 do zip com o `SHA256SUMS.txt` desta página (no PowerShell: `Get-FileHash .\arquivo.zip`).
