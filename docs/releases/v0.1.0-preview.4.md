## English

**Summary:** the fourth test version. It adds a **"Create profile for this device"** button to the Devices screen, so you no longer have to copy a device name by hand into the Profiles screen. It still has no installer and no code signing (SmartScreen warning).

### What changed
- **New, Create profile for this device:** on the **Devices** screen, select a device and click **Create profile for this device**. The app opens the **Profiles** screen with a new profile already filled in with the device name (as the profile name and as the device name to match). Nothing is saved until you set the options you want and save it yourself, and a message on the screen says so.
- **New, Open this device's profile:** if the selected device already has a profile that lists its name, the button changes to **Open this device's profile** and takes you straight to that profile instead of creating a duplicate.
- **Tested before this version:** the Devices screen from preview.3 was checked on a real PC (device name, connection count, last connection and profile used all showed correctly).

### How to update
1. Quit the app: right-click the tray icon and choose **Exit** (**Sair** in the Portuguese interface).
2. Unzip the new zip and **replace** `SunshineHelper.exe` and `SunshineHelper.Trigger.exe` in your folder with the new ones.
3. Open `SunshineHelper.exe`. Your settings, profiles, device list and the "Start with Windows" option are kept. Nothing changes in Sunshine.

### What does not work yet or needs care
- **No installer and no code signing** (hence the SmartScreen warning).
- This is the first package with the new button: it has automated tests, but it was not yet tried on a real PC. If something looks wrong, please say so (the diagnostic report on the General screen helps).
- A device whose name matches a profile only through the default profile is treated as having no profile of its own, so the button offers to create one.
- The **Log** screen and the gamepad overlay do not exist yet.
- If you open a second copy of the app, it closes silently (only one copy can be open): use the tray icon to bring the window up.
- Tested so far only on Windows 11, with Sunshine for Windows, RTSS 7.3.x and Playnite.

### How to check the file
Compare the zip's SHA256 with the `SHA256SUMS.txt` on this page (in PowerShell: `Get-FileHash .\file.zip`).

## Português

**Resumo:** quarta versão de testes. Ela traz o botão **"Criar perfil para este aparelho"** na tela Dispositivos, então você não precisa mais copiar o nome do aparelho à mão para a tela Perfis. Continua sem instalador e sem assinatura de código (aviso do SmartScreen).

### O que mudou
- **Novo, Criar perfil para este aparelho:** na tela **Dispositivos**, selecione um aparelho e clique em **Criar perfil para este aparelho**. O app abre a tela **Perfis** com um perfil novo já preenchido com o nome do aparelho (como nome do perfil e como nome do aparelho a reconhecer). Nada é salvo até você ajustar as opções que quiser e salvar por conta própria, e uma mensagem na tela avisa isso.
- **Novo, Abrir o perfil deste aparelho:** se o aparelho selecionado já tem um perfil que lista o nome dele, o botão muda para **Abrir o perfil deste aparelho** e leva direto a esse perfil, em vez de criar um duplicado.
- **Testado antes desta versão:** a tela Dispositivos da preview.3 foi conferida num PC de verdade (nome do aparelho, número de conexões, última conexão e perfil usado apareceram certos).

### Como atualizar
1. Saia do app: clique com o botão direito no ícone da bandeja e escolha **Sair**.
2. Descompacte o zip novo e **substitua** `SunshineHelper.exe` e `SunshineHelper.Trigger.exe` na sua pasta pelos novos.
3. Abra o `SunshineHelper.exe`. Suas configurações, perfis, lista de aparelhos e a opção "Iniciar com o Windows" são mantidos. Nada muda no Sunshine.

### O que ainda não funciona ou exige cuidado
- **Sem instalador e sem assinatura de código** (por isso o aviso do SmartScreen).
- Este é o primeiro pacote com o botão novo: ele tem testes automáticos, mas ainda não foi tentado num PC de verdade. Se algo parecer errado, avise (o relatório de diagnóstico da tela Geral ajuda).
- Um aparelho cujo nome só corresponde ao perfil padrão é tratado como sem perfil próprio, então o botão oferece criar um.
- A tela **Log** e o overlay pelo controle ainda não existem.
- Se você abrir uma segunda cópia do app, ela fecha em silêncio (só pode haver uma cópia aberta): use o ícone da bandeja para trazer a janela.
- Testado até agora só em Windows 11, com o Sunshine para Windows, RTSS 7.3.x e Playnite.

### Como conferir o arquivo
Compare o SHA256 do zip com o `SHA256SUMS.txt` desta página (no PowerShell: `Get-FileHash .\arquivo.zip`).
