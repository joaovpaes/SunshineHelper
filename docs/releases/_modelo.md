## English

**Summary:** one or two sentences: who this version is for and the most important thing it brings.

### What changed
- **New:** what the user can now do, where it is on screen and what it is for.
- **Improved:** what got better or clearer.
- **Fixed:** the problem the user used to see that no longer happens.

### How to update
1. Short step by step (for example: quit the app from the tray, replace the files, open it again).
2. Say what is kept (settings) and what must be redone, if anything.

### What does not work yet or needs care
- Known limits of this version (no installer, no code signing, what was not tested).

### How to check the file
Compare the zip's SHA256 with the `SHA256SUMS.txt` on this page (in PowerShell: `Get-FileHash .\file.zip`).

## Português

**Resumo:** uma ou duas frases: para quem é esta versão e o que ela traz de mais importante.

### O que mudou
- **Novo:** o que o usuário passa a poder fazer, onde fica na tela e para que serve.
- **Melhorado:** o que ficou melhor ou mais claro.
- **Corrigido:** o problema que o usuário via e que não acontece mais.

### Como atualizar
1. Passo a passo curto (por exemplo: feche o app pela bandeja, troque os arquivos, abra de novo).
2. Diga o que é mantido (configurações) e o que precisa ser refeito, se houver algo.

### O que ainda não funciona ou exige cuidado
- Limites conhecidos desta versão (sem instalador, sem assinatura de código, o que não foi testado).

### Como conferir o arquivo
Compare o SHA256 do zip com o `SHA256SUMS.txt` desta página (no PowerShell: `Get-FileHash .\arquivo.zip`).
